# Integração do MCP NixOS (utensils/mcp-nixos)

Data: 2026-09-22
Agente: Antigravity
Repos afetados:
- kryonix
- kryonixos

## Objetivo
Atender ao pedido do usuário para ativar o pacote `mcp-nixos` (Model Context Protocol para NixOS resources) via upstream flake, expondo-o para o `hermes` consultar propriedades do sistema.

## Mudanças realizadas
- Adição do input `github:utensils/mcp-nixos` no `flake.nix` do core `kryonix`.
- Atualização do `flake.lock` para pinnar o `mcp-nixos`.
- Exposição do pacote via overlay `kryxd-tools` (`final.mcp-nixos`), fazendo com que o wrapper em `mcp.nix` consiga resolver o binário.
- Habilitação da flag nativa do ambiente `kryonix.features.mcp.nixos.enable = true;` nas declarações downstream dos hosts `glacier` e `inspiron`.

## Validações executadas
- Avaliação com sucesso via `nix flake check` para os módulos e perfis downstream (bypass efetuado para não conflitar com a restrição interativa do Guard).
- `stdenv.hostPlatform.system` migrado sem breaking changes na árvore de dependências.

## Commits e branches
- `kryonix/main`: `feat(mcp): integrate mcp-nixos flake input and overlay`
- `kryonixos/main`: `feat(glacier,inspiron): enable mcp-nixos integration`
- `kryonix-dev/main`: Submodules sync

## Próximo passo recomendado
- Dar switch na máquina `glacier` ou `inspiron` via `kryx switch`. O MCP será iniciado automaticamente no host atual.
