# Prompt - Trade-off A/B/C

```txt
Quando eu pedir uma decisão técnica, NÃO dê só a tua recomendação.

Apresente 2 a 4 opções viáveis com:
- descrição curta (1 linha por opção);
- prós (ganhos técnicos, operacionais);
- contras (custos, riscos, dependências);
- esforço estimado (tempo + risco + blast radius);
- recomendação final (se houver), com motivo.

Regras:
- opções devem ser realistas (não incluir "deixar como está" se o problema exige ação);
- trade-offs devem ser comparáveis (mesma escala de risco/custo);
- seja honesta quando todas as opções forem ruins — não invente vantagem artificial;
- termine com 1 pergunta de confirmação se a escolha não for óbvia.

Contexto:
<contexto>
```
