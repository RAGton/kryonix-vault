# Playbook - Criar Projeto Novo

## Objetivo

Iniciar projeto vendável com base técnica limpa.

## Procedimento

1. Definir problema real.
2. Criar README.
3. Criar `PROJECT_SUMMARY.md`.
4. Criar `AGENTS.md`.
5. Criar stack mínima.
6. Criar testes iniciais.
7. Criar CI.
8. Criar OpenAPI se for API.
9. Criar `.env.example`.
10. Criar plano de deploy e rollback.

## Checklist

- [ ] problema claro
- [ ] usuário alvo
- [ ] MVP limitado
- [ ] testes
- [ ] CI
- [ ] segurança mínima
- [ ] docs mínimas
