# Playbook - Configurar Repo para Codex

## Objetivo

Preparar um repo para agentes trabalharem com segurança.

## Procedimento

1. Criar `AGENTS.md`.
2. Criar `PROJECT_SUMMARY.md`.
3. Documentar comandos de teste.
4. Criar issues pequenas.
5. Proteger secrets.
6. Garantir CI.
7. Definir fora do escopo.
8. Exigir PR pequeno.
